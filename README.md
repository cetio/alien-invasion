# Alien Invasion

[![License](https://img.shields.io/badge/License-Apache--2.0-blue)](LICENSE.txt)

A pixel art space shooter built with Pygame for CSCI-1511, following
Track 2: Custom Game Assets.

## Quick Start

Requires Python 3.12 or newer.

```sh
python -m pip install -r requirements.txt
python alien_invasion.py
```

Click Play to start. Use the arrow keys to move, Space to fire, and Q to quit.

For milestone demos, add `--milestone 1` or `--milestone 2` to the launch command.
The default is the final build.
